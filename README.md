# 🏔️ HimalayaGuard AI (हिमालय गार्ड)

**Smart India Hackathon — Problem Statement 26192 (NDRF / Ministry of Home Affairs)**

AI-powered Disaster Management & Early Warning Web Application for Himalayan flash floods and landslides.

## ✨ Features
- 🌐 Fully bilingual (English / हिन्दी)
- 🛰️ Multi-source AI prediction dashboard (satellite, river gauges, soil sensors)
- 🗺️ Topographic risk map with live zones
- 🆘 Citizen SOS with GPS → NDRF Commander live feed
- 🔥 Firebase-ready architecture
